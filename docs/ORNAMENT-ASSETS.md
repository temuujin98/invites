# Чимэглэлийн элементүүд

Урилгын захидлын загварын (`layout: 'letter'`) хүрээ, ирмэг, булангийн хээ.

## Яагаад SVG вэ

Эхэндээ AI-аар PNG үүсгэхээр төлөвлөсөн боловч шугаман чимэглэлд растер зураг
буруу хэрэгсэл болох нь тодорхой болсон:

| | AI PNG | SVG (одоогийн) |
|---|---|---|
| Нийт хэмжээ | 500KB – 1MB | **~2.2KB** |
| Томсгоход | бүдгэрнэ | хурц хэвээр |
| 12 загварын өнгө | загвар бүрт дахин үүсгэх | нэг ассет бүгдэд |
| Давтахад залгаас | эрсдэлтэй | геометрээр баталгаатай |
| Өртөг | API төлбөртэй | үнэгүй |

## Файлууд

**Давтагдах хоёр — `client/public/ornaments/`** (CSS `mask`-аар ашиглагдана):

| Файл | Үүрэг | Хэмжээ |
|---|---|---|
| `lace-edge.svg` | Сүлжмэл ирмэг, хэвтээ давтагдана | 647B |
| `frame-side.svg` | Навчит мөчир, босоо давтагдана | 881B |

**Ганц удаагийнх — `client/src/invite/ornaments/Ornaments.jsx`** (inline React SVG):

`Corner` · `Divider` · `SealEmblem`

## Давтагдалт хэрхэн залгаасгүй болсон

- **`lace-edge.svg`** — нэг таhлбарт яг нэг хагас дугуй, радиус нь хайрцгийн
  өргөний яг тал (`r=20`, `viewBox` өргөн `40`). Тиймээс хөрш дугуйнууд ирмэг
  дээрээ шүргэлцэнэ — завсар ч, давхцал ч үүсэхгүй.
- **`frame-side.svg`** — иш нь дээд ба доод ирмэг дээр **яг ижил `x=12`**
  байрлалаас гардаг. Дараалуулан давтахад тасралтгүй нэг мөчир болно.

⚠️ Эдгээр файлыг засах бол дээрх хоёр нөхцөлийг заавал хадгална. Эс тэгвэл
давталтын залгаас тодорхой харагдана.

## Өнгө — нэг ассет, 12 загвар

Давтагдах хоёрыг `mask-image`-ээр ашигладаг: SVG нь зөвхөн **хэлбэрийг** (alpha
сувгаараа) өгч, өнгө нь `background-color`-оос ирнэ.

```css
.lt-edge { background-color: var(--ink-soft); }   /* өнгө эндээс */
.lt-edge-top { mask-image: url('/ornaments/lace-edge.svg'); mask-repeat: repeat-x; }
```

Inline компонентууд `currentColor` ашигладаг тул CSS-ийн `color`-оос өнгөө авна.

Загвар бүрийн өнгө нь `styles.css` доторх `.pv.layout-letter.tone-*` дүрмүүдэд
`--env`, `--ink`, `--ink-soft`, `--gold` хувьсагчаар тодорхойлогддог. Шинэ өнгө
нэмэхэд ассет дахин үүсгэх шаардлагагүй — зөвхөн нэг мөр CSS нэмнэ.

## Хэмжээ тохируулах

Булангийн хээ хэт том/жижиг санагдвал:

```css
.lt-corner { width: clamp(44px, 12vw, 70px); }
```

Сүлжмэл ирмэгийн зузаан:

```css
.lt-edge-top, .lt-edge-bottom { height: 22px; }
```

## Фон зураг (тусдаа асуудал)

Захидлын загвар фон зураг ашигладаггүй — дугтуй нь цул өнгө. Бусад загварууд
`client/public/backgrounds/<template-id>.jpg`-г бүтэн дэлгэцийн фон болгон
ашигладаг ба одоогийн 12 файлын **11 нь хэвтээ** (жишээ нь `forest-corporate`
960×399). Утасны босоо дэлгэцэд `cover`-оор тавихад төвийн нарийн зурвас л
үлдэж бүдгэрдэг. Босоо 9:16 зургаар солих нь хүлээгдэж буй ажил;
санаа авах материалыг `client/public/backgrounds/source/` дотор хийнэ.
